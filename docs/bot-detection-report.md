# Bot detection: evaluation report

Generated by `brisca detect train`. All data is **synthetic** (see `brisca.detection.simulate` and the model card).

- 2,000 players, 6,074 sessions, 16.0% bot sessions
- 5-fold cross-validation grouped by player; the operating point flags at most 1.0% of human sessions
- `mimic` bots are never trained on (unseen-adversary test)
